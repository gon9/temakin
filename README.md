# 手巻きファイター (temakin)

作った手巻き寿司が、そのまま戦うキャラクターになるパーティーゲーム。

手巻き寿司パーティーで実物の手巻きをスマホカメラでスキャンすると、見た目（大きさ・色・巻きの綺麗さ・具のはみ出し具合）から戦闘キャラ「手巻きファイター」が生成され、オートバトルで対戦します。勝敗が決まったら食べて、また次の一本を巻く。

```
巻く（戦略） → スキャン（生成） → バトル（観戦） → 食べる（リセット） → もう一本
```

- サーバー不要・インストール不要のモバイルWebアプリ（PWA）
- 撮影画像はすべて端末内で処理し、外部に送信しない
- ネタ識別AIは使わず、色・形の特徴量からステータスを決定的に生成
