# 手巻きファイター 要件定義書

- ステータス: ドラフト
- 最終更新: 2026-07-04
- 関連ドキュメント: [デザインドック](./design.md)

## 1. コンセプト

**「作った手巻き寿司が、そのまま戦うキャラクターになる」**

手巻き寿司パーティーの席で、各プレイヤーが実物の手巻き寿司を作り、スマホのカメラでスキャンする。手巻きの見た目（色・大きさ・巻きの綺麗さ・具のはみ出し具合）から戦闘キャラクター「手巻きファイター」が生成され、オートバトルで対戦する。勝敗が決まったら食べて、また次の一本を巻く。

「何をどう巻くか」がそのままキャラビルドになるため、手巻き寿司を作る行為自体がゲームの戦略パートになる。ゲームが食事を中断させるのではなく、食事を加速させることを最重要の設計原則とする。

## 2. ターゲットと利用シーン

| 項目 | 内容 |
|---|---|
| 利用シーン | 家庭・友人宅での手巻き寿司パーティー（2〜8人程度） |
| プレイヤー | 子どもから大人まで。ゲームの説明を読まなくても遊べること |
| デバイス | 参加者のうち1台のスマートフォンを回して共有する |
| プレイ時間 | 1バトル（作る→スキャン→対戦→食べる）で5〜10分。食事の間に何度も回す |

## 3. ゲームの基本ループ

```
① 巻く      … 各プレイヤーが実物の手巻きを1本作る（戦略パート）
② スキャン   … 外カメラで手巻きを撮影 → ファイター生成（ドキドキパート）
③ バトル    … 生成されたファイター同士がオートバトル（観戦パート）
④ 食べる    … 勝敗確定。自分の手巻きを食べて次のラウンドへ（リセット）
```

## 4. 機能要件

### 4.1 プレイヤー登録（顔ネタカード）

- ゲーム開始時に参加プレイヤーを登録する（2〜8人）
- 各プレイヤーはニックネームを入力し、インカメラで顔を撮影する
- 撮影した顔は背景を除去して切り抜き、「顔ネタカード」として保存する
- 顔はファイターの顔として合成される（自分の顔がついた手巻きが戦う）
- 顔撮影はスキップ可能（スキップ時はデフォルトのアバター顔を使用）

### 4.2 手巻きスキャン

- 外カメラ（リアカメラ）で完成した手巻き寿司を撮影する
- 撮影ガイド（枠と「手巻きを枠に収めてね」の表示）を出し、明るい場所での撮影を促す
- 撮影画像から手巻き領域を抽出し、画像特徴量を算出する
- 撮り直しは何度でも可能。ただし**スキャン確定後の撮り直しは不可**（ステータスガチャの再抽選を防ぐ）

### 4.3 ファイター生成（ステータス変換）

- 画像特徴量からファイターのステータスを**決定的に**生成する（同じ手巻きなら概ね同じステータスになる）
- 「ネタが何であるか」の識別は行わない。色・面積・形状などの特徴量のみを使う
- ステータス変換の方針（詳細アルゴリズムはDD参照）:

| ステータス | 由来する見た目の特徴 | 狙い |
|---|---|---|
| HP | 手巻きの大きさ（面積） | デカく巻けば硬い |
| 攻撃 | 赤系の色の強さ・彩度 | マグロ・エビ等の赤ネタは攻撃的 |
| 防御 | 巻きの整い度（輪郭の綺麗さ） | 丁寧に巻くと堅い |
| 素早さ | 明度・ツヤ | 光るネタ（サーモン等）は速い |
| 技の数 | 色のバリエーション数 | 具だくさんは多彩な技を持つ |

- 生成されたファイターには特徴量に応じた**二つ名**（例:「はみ出し狂戦士」「鉄壁の海苔巻き」）と**技名**を自動付与する
- ファイターのビジュアルは、スキャンした手巻きの実写画像＋プレイヤーの顔ネタを合成して生成する

### 4.4 バトル

- 2体のファイターによるターン制オートバトル
- プレイヤーの操作は不要（観戦して盛り上がるパート）。1バトル30〜60秒で決着する
- 技の発動・会心・回避などに乱数を含むが、ステータス差が概ね勝敗に反映されること（強い手巻きが大体勝つが、番狂わせもある）
- 3人以上の場合はトーナメント形式で総当たりまたは勝ち抜き戦を自動編成する
- バトル中は技名・ダメージ・実況テキストを派手に演出する（例:「〇〇のはみ出しアタック！ 具が飛び散った！」）

### 4.5 リザルトとシェア

- バトル終了後、勝者のファイター（実写手巻き＋顔）を讃えるリザルト画面を表示する
- リザルト画像（勝者の手巻き＋顔＋二つ名＋戦績）を端末に保存・共有できる（Web Share API）
- セッション中の戦績（誰が何勝したか）を集計し、パーティー終了時に「本日の手巻き王」を表彰する

## 5. 非機能要件

| 項目 | 要件 |
|---|---|
| プラットフォーム | スマートフォンのモバイルブラウザ（iOS Safari / Android Chrome）。アプリインストール不要、URLを開けば遊べる |
| 通信 | ゲームプレイにサーバー通信を必要としない。初回ロード後はオフラインで動作する（PWA） |
| プライバシー | 撮影した顔・手巻きの画像は端末外に送信しない。すべての処理を端末内で完結させる。セッション終了時に画像を破棄する（シェアはユーザーの明示操作のみ） |
| パフォーマンス | スキャン〜ファイター生成まで3秒以内。バトル演出は30fps以上 |
| 対応環境 | iOS 16+ / Android 10+ の標準ブラウザを目安とする |
| 照明条件 | 一般的な室内照明（食卓）で動作すること。極端な逆光・暗所は撮影ガイドで回避を促す |

## 6. スコープ外（将来検討）

- ネタの種類を識別するAI（「これはマグロ」等の判定は行わない）
- オンライン対戦・ランキング等のサーバー機能
- ミニゲーム（「ネタモン」「ネタ早取りバトル」「消えたネタはどれだ」）※同じスキャンエンジンの上に将来追加できる設計とする
- ファイターの永続コレクション（図鑑）
- 多言語対応（初期は日本語のみ）

## 7. 成功の定義

- 初見のプレイヤーが説明なしで1ループ（巻く→スキャン→バトル→食べる）を完走できる
- 1回の手巻きパーティーで自然に3ループ以上遊ばれる（＝食事を邪魔していない）
- 「攻撃型に巻くか防御型に巻くか」という会話が食卓で発生する
